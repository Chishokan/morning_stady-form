# 夏休み おはよう勉強会 申し込みフォーム

朝の勉強会の参加申し込みを受け付けるシンプルな Web フォームです。
申し込みログは **Google スプレッドシート** に自動で記録されます。

サーバー不要・無料で運用できます（GitHub Pages などの静的ホスティング + Google Apps Script）。

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 申し込みフォーム画面 |
| `style.css` | デザイン |
| `app.js` | 入力チェックと送信処理 |
| `config.js` | 送信先（GAS の URL）の設定 |
| `gas/Code.gs` | スプレッドシートに記録するバックエンド（Google Apps Script） |

## セットアップ手順

### 1. スプレッドシートと Apps Script を用意する

1. [Google スプレッドシート](https://sheets.new) を新規作成します（このシートに申し込みが溜まります）。
2. メニューの **拡張機能 → Apps Script** を開きます。
3. 既定の `コード.gs` の中身を、このリポジトリの [`gas/Code.gs`](gas/Code.gs) の内容にすべて置き換えて保存します。

### 2. ウェブアプリとしてデプロイする

1. Apps Script エディタ右上の **デプロイ → 新しいデプロイ** をクリック。
2. 種類の選択（歯車アイコン）で **ウェブアプリ** を選びます。
3. 設定は次の通り:
   - **次のユーザーとして実行**: 自分
   - **アクセスできるユーザー**: **全員**
4. **デプロイ** を押し、表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/.../exec`）をコピーします。
   - 初回は Google アカウントの承認を求められます。画面に沿って許可してください。

> デプロイ後に `Code.gs` を編集したときは、**デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン: 新バージョン → デプロイ** で反映してください。

### 3. フォームに URL を設定する

`config.js` を開き、コピーした URL を貼り付けます。

```js
window.APP_CONFIG = {
  GAS_ENDPOINT: "https://script.google.com/macros/s/AKfycb.../exec",
};
```

### 4. 公開する

`index.html` を開けばそのまま使えます。全員に配布するなら静的ホスティングで公開します。

**Vercel で公開する例（推奨）:**

このリポジトリはビルド不要の静的サイトなので、そのまま公開できます。

1. [Vercel](https://vercel.com/) にログインし、**Add New → Project** からこの GitHub リポジトリをインポートします。
2. Framework Preset は **Other**（自動検出のままでOK）、Build 設定は空のままで **Deploy** を押します。
   - `vercel.json` を同梱しているので、追加設定は不要です。
3. 発行された URL（`https://<プロジェクト名>.vercel.app`）を参加者に共有します。

> `main`（またはデフォルトブランチ）へ push するたびに Vercel が自動で再デプロイします。
> CLI を使う場合は、リポジトリ直下で `npx vercel --prod` でも公開できます。

**GitHub Pages で公開する例:**

1. GitHub の **Settings → Pages** を開く。
2. Source を `Deploy from a branch` にし、対象ブランチと `/ (root)` を選んで保存。
3. 表示された URL を参加者に共有します。

## 動作確認

- ブラウザで `index.html` を開き、フォームを送信します。
- スプレッドシートの「申し込みログ」シートに行が追加されれば成功です。
- GAS の URL をブラウザで直接開くと稼働確認メッセージが表示されます。

## 収集する項目

- 受付日時（自動）
- お名前（必須）
- メールアドレス（必須）
- 学年・所属（必須）
- 参加希望曜日（必須・複数選択可）
- 目標・意気込み（任意）

項目を変えたいときは `index.html` のフォームと `gas/Code.gs` の `HEADERS` / `appendRow` を合わせて編集してください。

## 補足

- フォームは CORS のプリフライトを避けるため `text/plain` + `no-cors` で送信します。そのためブラウザ側では送信の成否を厳密には判定できませんが、通常のネットワーク環境では確実に記録されます。
- 迷惑送信が心配な場合は、GAS 側で受付期間や1メールアドレスあたりの回数制限などを追加できます。
